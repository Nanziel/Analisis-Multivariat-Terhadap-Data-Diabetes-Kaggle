# 📊 Multivariate Analysis: Diabetes Health Indicators

An in-depth **Exploratory Data Analysis (EDA)** project developed as a **final assignment for Multivariate Analysis (Class B083)**.
This project demonstrates the implementation of **data preprocessing, feature engineering, and statistical visualization** using **Python**.

The analysis is designed for **students and data analysts** who want to understand the correlation between various health risk factors—such as **BMI, Age, and Gender**—and the **prevalence of diabetes**.

---

## 🚀 Key Features

### 🧹 Data Preprocessing

* **Cleaning & Validation**: Automatically checks for missing values and verifies data types.
* **Data Integrity**: Ensures the dataset is prepared for accurate statistical analysis.

### 📊 Demographic & Gender Analysis

* **Distribution Insights**: Visualizes the spread of *Diabetes*, *Prediabetes*, and *Healthy* individuals across genders.
* **Visual Comparisons**: Uses bar charts to highlight disparities between demographic groups.

### ⚖️ BMI & Health Trends

* **Feature Engineering**: Transforms numerical BMI values into categorical groups:

  * Underweight
  * Normal
  * Overweight
  * Obesity
* **Correlation Analysis**: Heatmaps are used to visualize the relationship between BMI categories and diabetes status.

### 👴 Age Distribution Analysis

* **Age Binning**: Converts coded age values into readable age ranges for better interpretability.
* **Multivariate Plotting**: Pairplots are implemented to observe interactions between:

  * Age
  * High Cholesterol
  * High Blood Pressure
